# Catalog baseline — findings (2026-10-23)

Surfaced while cataloguing `main` @ `e0036d7` (v1.2.0 + patches). **Nothing here has been changed** — each
item is a decision for the project lead. Every item is also recorded on the affected file's catalog entry
(caveats). ✅ = verified against the source by hand; the rest come from the per-area review and should be
confirmed before acting.

## 2. Broken script

- ✅ `repopulate_DimCalendar.sql` TRUNCATEs DimCalendar then INSERTs without `LastUpdated` (NOT NULL) — the
  insert fails and leaves the calendar EMPTY, which breaks every benchmark-month lookup.

## 3. Behaviour that may be wrong (assessment / data decisions)

- ✅ **English reading for French Immersion students gets no delta.** `usp_UpsertReadingAssessment` looks up
  DimReadingBenchmark by the student's ProgramFamily (equality); no `EN_Reading × French Immersion` rows are
  seeded → FI grade-3+ / J020 English reading stores ReadingDelta NULL.
- **IPP / Adaptation decisions revert to "unresolved"** when a student re-versions (e.g. homeroom change):
  `usp_MergeStudent` closes the rows under the old StudentKey and opens NULL rows under the new one.
- **Same-day IPP/Adaptation toggles** can leave EffectiveEndDate < EffectiveStartDate; DQ checks don't cover
  FactStudentIPP / FactStudentAdaptation / FactAssessmentMath.
- ✅ **Clearing a math cell can resurface an older result** (only the same-date row is deleted).
- **A failed DQ gate leaves partial state:** the five merges have committed; roster membership isn't rebuilt.
- `usp_UpsertShortCycleHeader` doesn't propagate the header's ActiveFlag to its instance windows; new/edited
  cycles have no roster membership until the next ingest.

## 4. App / proc hygiene

- ✅ `ingest/actions.ts` (line 132) shows raw `e.message` on failure — SQL/driver text can reach the screen;
  the "maintenance left ON" suffix also appears when nothing was scheduled.
- `/cycles` actions throw plain `Error` (Next hides these in production → generic error instead of the proc's message).
- `confirmRosterIPPs` / `saveProgramming` pre-loop setup isn't wrapped; ProgrammingRosterGrid has no try/catch
  or draft; `confirmRosterIPPs` doesn't clear the group cache.
- ✅ THROW numbers collide: **51040** = not-sysadmin / grace-lock / blank CycleGroupID; **51041** = two meanings;
  51030–51037 overlap permission codes. (`by-error.md` lists each with its source.)
- ✅ `usp_UpsertStudentIPP` / `usp_UpsertStudentAdaptation` carry no GRANT — a redeploy drops the app's EXECUTE
  until `grant_webapp_sp.sql` is re-run.
- `usp_LoadMathTasks` COPY INTO lacks the Workspace Identity credential (#1119 workaround) — may fail as the app SP.
- `getStudentRWMHistory` skips the 1–20-digit StudentKey check the other history functions do.
